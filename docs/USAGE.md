# 使用手册

打开 `http://127.0.0.1:8001` 后，主界面是一个对话框。以下按功能说明。

## 1. 对话与文件操作

直接在对话框里用自然语言下达任务，例如：

- “列出当前项目的文件结构”
- “把 `src/app.py` 里的超时改成 30 秒”
- “搜索所有 TODO 并汇总”

Agent 会在授权后调用文件工具读写文件、执行搜索。涉及写操作会走安全策略确认。

## 2. 联网与多模态

- **网页搜索 / 抓取**：让 AI 搜索网页或读取某个 URL 的正文；无头浏览器支持 JS 渲染页面。
- **图片 / 语音**：可作为对话输入做识别（OCR / ASR）；文生图工具可按描述生成图片。

## 3. 工作流

在「工作流」页用可视化编辑器把多步任务串成流程，保存后可反复运行，也可在对话里触发。工作流支持条件分支、代码节点（可读写插件数据）与工具调用节点。

## 4. 知识库

在「知识库」页把文档（PDF / 网页 / 文本）入库，之后对话即可基于文档问答。检索使用本地向量索引，数据不出本机。

## 5. 插件

在项目主页「登记」插件包后即可使用其工具 / 工作流 / 页面。详见 [插件开发指南](PLUGIN_DEV_GUIDE.md)。

## 6. 模型设置

在「设置」页添加 LLM provider（baseUrl + API Key）。可配置多个账号，支持出站切换插件接管请求。

## 7. 安全与数据

- 所有数据默认存本地 `data/`，不上传。
- 工具调用经策略引擎管控；敏感操作需确认。
- 自托管部署时建议仅监听 `127.0.0.1`，或用反向代理加鉴权后再对外暴露。
